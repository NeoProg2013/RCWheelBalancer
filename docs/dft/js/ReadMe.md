Рассмотрим дискретное преобразование Фурье (DFT) на формулах, чтобы понять, что происходит “под капотом”.
Определение DFT
Для последовательности из N отсчётов\( x[0], x[1], ..., x[N-1] \)
DFT вычисляет набор "частотных" коэффициентов \( X[k] \):
\[
X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j\frac{2\pi}{N}kn}
\]
где:
\( k = 0, 1, ..., N-1 \) — индекс частоты,
\( n \) — индекс по времени,
\( j \) — мнимая единица.
Обратное преобразование (IDFT):
\[
x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] \cdot e^{j\frac{2\pi}{N}kn}
\]
Как это понимать
DFT разбирает исходный сигнал на сумму синусоид разных частот, амплитуд и фаз.
Коэффициенты \( X[k] \) указывают, сколько в исходном сигнале синусоиды частоты \( k \).
Пример для маленького N (наглядно):
Пусть \( N = 4 \):
\[
\begin{align*}
X[0] &= x[0] + x[1] + x[2] + x[3] \\
X[1] &= x[0] + x[1] e^{-j\frac{2\pi}{4}1} + x[2] e^{-j\frac{2\pi}{4}2} + x[3] e^{-j\frac{2\pi}{4}3}\\
X[2] &= x[0] + x[1] e^{-j\frac{2\pi}{4}2} + x[2] e^{-j\frac{2\pi}{4}4} + x[3] e^{-j\frac{2\pi}{4}6}\\
X[3] &= x[0] + x[1] e^{-j\frac{2\pi}{4}3} + x[2] e^{-j\frac{2\pi}{4}6} + x[3] e^{-j\frac{2\pi}{4}9}
\end{align*}
\]
Интерпретация
Каждый \( X[k] \) — это проекция сигнала на комплексную синусоиду частоты \( k \).
Если в сигнале есть гармоника соответствующей частоты, \( |X[k]| \) будет велико.
